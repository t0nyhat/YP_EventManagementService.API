## Что принципиально изменилось относительно sprint 7

- Появилась сущность `User` (логин, хеш пароля, роль) и перечисление ролей `User` / `Admin`.
- `Booking` связан с пользователем через `UserId`; создание брони требует идентификатора пользователя.
- У брони появился статус `Cancelled` и операция отмены с защитой от повторной отмены.
- Введены доменные правила: запрет брони прошедшего события, лимит активных броней (10), проверка прав при отмене.
- Добавлены security-примитивы: SHA-256 хеширование паролей и генерация JWT-токена; параметры токена вынесены в конфигурацию.
- В Web API подключены JWT-аутентификация и авторизация по ролям; управление событиями доступно только `Admin`.
- Новые правила и сценарии авторизации покрыты unit- и integration-тестами.
