# Введение и обзор проекта

## Назначение проекта

**EventManagementService.API** — это учебный REST API сервис для управления событиями (CRUD), разработанный на ASP.NET Core 10.0. Проект демонстрирует базовые принципы построения веб-API с использованием современных практик .NET, таких как внедрение зависимостей (DI), разделение слоёв, валидация данных, документация через Swagger/OpenAPI и обработка ошибок.

Основная цель проекта — не только реализовать функциональность управления событиями, но и служить наглядным примером для изучения архитектурных паттернов, принятых в экосистеме .NET.

## Ключевые характеристики

- **Полный CRUD** для сущности «Событие» (Event) с поддержкой операций создания, чтения, обновления и удаления.
- **Чистая архитектура** с разделением на контроллеры, сервисы, модели и DTO.
- **Валидация входных данных** на уровне DTO с использованием атрибутов `[Required]` и кастомной бизнес-логики (проверка дат).
- **Документация API** через Swagger UI в режиме разработки.
- **In‑memory хранилище** — данные сохраняются только на время жизни приложения (упрощённая реализация для учебных целей).
- **Потокобезопасность** — сервис использует блокировку (`lock`) для защиты коллекции от параллельных модификаций.
- **Локализованные сообщения об ошибках** на русском языке.

## Технологический стек

- **Платформа**: .NET 10.0 (ASP.NET Core Web API)
- **Язык**: C# 12
- **Документация**: Swashbuckle.AspNetCore (Swagger/OpenAPI)
- **Сборка и запуск**: dotnet CLI
- **Хранение данных**: In‑memory коллекция (`List<Event>`)
- **Валидация**: DataAnnotations (`Required`, кастомные проверки)

